## Getting start

1. Install dependency

   ```
   go mod vendor
   ```

2. rename ".env.template" to ".env"

   ```
    PORT=8080
    ENV=development
   ```

3. Running server

   Run normally

   ```
   go run ./cmd/server/main.go
   ```

   Run with live-reload

   Linux/MacOS

   ```
   air
   ```

   Windows

   ```
   air -c .air.windows.toml
   ```
